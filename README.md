# Nottingham Guide

A mobile web app (PWA) for independent Nottingham: places to eat and drink, historic and cave pubs, quirky and independent shops, vintage, records and books, second-hand cameras, instruments and tech, cheese and world-food shops, escape rooms and games cafés, live music and comedy, parks and walks, small art galleries, and day trips out of the city. Every place has links to Google reviews, TripAdvisor, its own website where it has one, and walking directions in Apple Maps or Google Maps, plus a built-in map.

It's a plain static site with no build step. Open `index.html` or host the folder anywhere (GitHub Pages, Vercel, Netlify). The `build/` folder holds the Python scripts that generate `data.js` and the illustrations.
